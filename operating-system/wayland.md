# Wayland

**Display server: Wayland (intentional choice).**

- Prefer solutions compatible with **KDE Plasma + Wayland + NVIDIA**.
- **Do not switch back to X11** unless genuinely required — treat X11 as a
  last-resort fallback with explicit justification, not a first fix.
