# Desktop environment

**KDE Plasma**

Runs on Wayland ([wayland.md](wayland.md)) on NVIDIA hardware
([../hardware/gpu.md](../hardware/gpu.md)).

Prefer solutions compatible with the **KDE Plasma + Wayland + NVIDIA** stack.

## Panel / taskbar

- [Taskbar shortcut groups](taskbar-shortcut-groups.md) — per-monitor "Launcher
  Group" widgets (a custom local plasmoid) whose shortcuts hide while their app
  has a visible window; declared in `users/ethan/kde-taskbar-groups.conf`.
