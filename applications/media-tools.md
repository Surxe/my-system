# Media tools

- **OBS** — screen/stream recording
- **Kdenlive** — video editing
- **Avidemux** — quick cut/encode
- **Pinta** — raster image editing
- **spotifixed** — cached Spotify playlists through mpv with a lyric overlay; see [spotifixed.md](spotifixed.md)

All run under KDE Plasma + Wayland.
