# Deployable artifacts (now version-controlled here)

The privileged host scripts, ethan's shell modules, and dev's config are now
tracked **in this repo** and deployed to their live locations by
[`../users/install.sh`](../users/install.sh). This replaces the earlier
"uncommitted on disk" state.

| Live location | Source of truth (in repo) | Tier / deploy |
| --- | --- | --- |
| `/usr/local/sbin/devscaffold` | [`system/usr-local-sbin/devscaffold`](../system/usr-local-sbin/devscaffold) | root; `install.sh` (sudo, `0755`) |
| `/usr/local/sbin/devperms` | [`system/usr-local-sbin/devperms`](../system/usr-local-sbin/devperms) | root; `install.sh` (sudo, `0755`) |
| `/etc/sudoers.d/devscaffold` | [`system/etc-sudoers.d/devscaffold`](../system/etc-sudoers.d/devscaffold) | root; `install.sh` (sudo, `0440` + `visudo -cf`) |
| `~ethan/.bashrc.d/*.sh` | [`users/ethan/.bashrc.d/`](../users/ethan/.bashrc.d/) | ethan; `install.sh` (copy + review gate) |
| `~ethan/.config/devscaffold/token` | not tracked — secret; `token.example` only | never committed ([secrets-policy](../private/secrets-policy.md)) |
| `~dev/.claude/CLAUDE.md` | [`users/dev/`](../users/dev/) (generated by `build-claude-md.sh`) | dev; `install.sh` (copy) |

## How deploy works and its trust model

`install.sh` copies privileged (ethan/root) files **from the working tree**, which
is dev-writable. To keep the merge gate meaningful it runs a **review gate**: each
privileged file is diffed against the ethan-approved `origin/master` and requires
explicit confirmation if it differs. This narrows — but does not close — the window
where a local edit reaches ethan/root before you review. See
[git-workflow.md](git-workflow.md) for the full rationale and the accepted trade-off.
