# Compatibility notes

Gaming stack: **KDE Plasma + Wayland + NVIDIA RTX 5070**.

- Prefer solutions compatible with Wayland; don't fall back to X11 as a first fix
  ([../operating-system/wayland.md](../operating-system/wayland.md)).
- NVIDIA Vulkan support works — see
  [../troubleshooting/solved-issues.md](../troubleshooting/solved-issues.md) for
  the resolved detection/Chromium history.
- Keep the proprietary driver stable ([nvidia.md](nvidia.md)).
