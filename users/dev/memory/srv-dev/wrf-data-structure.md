Navigation map for the WRFrontiersDB data.

## Orchestrator working tree: `/srv/dev/wrf/data/`

Generated by the `WRFrontiersDB-Orchestrator` pipeline (steam depot -> UE export
-> parse -> textures -> publish). Everything here is generated; not a source of
truth. Stages, in order:

1. `steam-download/` — raw depot via DepotDownloader. Input to the exporter.
2. `exports/WRFrontiers/Content/...` — full UE asset export (JSON + PNG), from
   `WRFrontiers-Exporter`; mirrors the game content path tree.
3. `mapper/*.usmap` — Unreal mappings used to parse packages.
4. `parsed/` — parsed game data (JSON only), staged for publish; same shape as
   the Data repo's `current/`. Local git dir, no remote.
5. `textures/WRFrontiers/Content/...` — rendered PNG icons, path-mirrored.

`*.log` files are export run output.

## Published artifact: `WRFrontiersDB-Data` repo

Both consumer sites (`WRFrontiersDB-Site`, `WRFrontiers-Discount-Visualizer`)
read the Data repo `Surxe/WRFrontiersDB-Data`
(`/srv/dev/repos/WRFrontiersDB-Data`), NOT the working tree. Contents:

- `current/` — parsed JSON payload:
  - `Objects/` — 46 game-object tables, one JSON file each (see below).
  - `Localization/` — `en.json`, `de.json`, ... keyed by localization Key.
  - `Analysis/` — derived tables (costs, discounts, upgrade diffs).
  - `Image.json` — flat list of every known texture path.
  - `version.txt` — patch/version stamp.
- `textures/WRFrontiers/Content/...` — ~600 rendered PNGs, path-mirrored.

## Key object files (`Objects/`)

- `VirtualBot.json` — the 41 playable/factory bots. Each: `id`, localized `name`,
  `character_type` (Titan/Mech), `core_module_refs`, `factory_preset_refs`
  (`OBJID_CharacterPreset::DA_Preset_*`), `icon_path`.
- `CharacterPreset.json` — factory presets referenced by bots.
- `Module.json` / `CharacterModule.json` / `ModuleStat*.json` — module system.
- `Pilot*.json`, `Ability.json`, `Skin.json`, `ShopCard.json`, etc.
- Cross-reference id format between tables: `OBJID_<Type>::DA_<Name>.<n>`.
