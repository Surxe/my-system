Never use emojis or emoticons in any written file (code, docs, commits, configs). They are allowed exclusively in the chat conversation itself.

**Why:** Ethan's preference for clean, professional file content.

**How to apply:** In files use plain text markers (e.g. words, `[x]`/`[ ]`, "yes/no") instead of emoji; keep emoji to chat replies only.
